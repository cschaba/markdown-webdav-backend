# Editable Markdown & WEBDAV Server

I want to have a Webserver with following features:

- Render Markdown Files to HTML
- I want to be able to create and edit the Markdown Files from e.g. Obsidian or Logseq from different platforms like Laptop, Mobile, Tablet, mainly Linux-Laptop, Macbook, iPhone and iPad
- It should support attachments in Markdown pages
- It should support versioning, maybe via GIT
- It should support Obsidian like Front-Matter and tags and links
- It should support mermaid diagrams
- It should support syntax highligt for code blocks
- It should support the "base" feature like in Obsidian
- Techstack: GO or in Docker, best without database just plain files -> simple self-hosted
